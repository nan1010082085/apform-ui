# 国际化（i18n）

## 文档站

playground 顶栏可切换中/英界面文案（侧栏分组等）。**组件运行时文案**不随文档站语言自动切换。

## 组件内置中文

常见硬编码：FilterBar「查询/重置」、部分空态、确认框默认文案。覆盖方式：

- 插槽覆盖按钮（`FilterBar` `#actions`）
- `useConfirm` / `useMessage` 传入自定义 `title` / `message`
- `EmptyState` 的 `title` / `description` props
- Element Plus 本身用 `ElConfigProvider` locale

## 清单（持续补充）

| 位置 | 默认文案 | 覆盖方式 |
|------|----------|----------|
| FilterBar 默认按钮 | 查询 / 重置 | `#actions` |
| useConfirm 删除模板 | 确认删除… | `confirmDelete` options |
| Composer placeholder | 可传 `placeholder` | prop |

完整英文包尚未作为一等公民；欢迎 PR。
