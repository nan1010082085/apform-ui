# 无障碍与移动端

## 键盘与 ARIA

- 对话框 / 确认框：依赖 Element Plus 焦点陷阱；自定义弹层需自行处理 Esc / Tab  
- Composer：Enter 发送（业务可改）；附件按钮需可见 label  
- SliderCaptcha：优先保证键盘可达与失败重试提示  

## 响应式

- `PageShell` 水平 padding 随 token；窄屏注意 FilterBar 换行  
- 对话侧栏在小屏建议业务自行改为抽屉，本库不强制响应式壳  

## 政企 / 出海

若招标要求 WCAG，请对目标页做 axe 扫描；本库提供基础语义，不宣称全量 AA 合规。优先补：弹窗、对话区、验证码。
