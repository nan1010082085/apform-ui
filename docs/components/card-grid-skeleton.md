# CardGridSkeleton 卡片网格骨架屏

用于卡片列表加载时的占位展示。跨 4 个项目存在完全相同的骨架屏 markup，此组件统一替代。

## 基础用法

<DemoBlock demo="CardGridSkeletonBasic" />

## API

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `count` | `number` | `6` | 骨架卡片数量 |
| `showThumb` | `boolean` | `true` | 是否显示缩略图区域 |
| `animated` | `boolean` | `true` | 是否开启动画 |
