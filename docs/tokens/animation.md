# 动画

定义在 `design-tokens.css`。

| Token | 值 |
|-------|-----|
| `--duration-fast` | 0.15s |
| `--duration-normal` | 0.25s |
| `--duration-slow` | 0.35s |
| `--easing-default` | ease |
| `--easing-spring` | cubic-bezier(0.34, 1.56, 0.64, 1) |

组合：`--transition-fast` / `--transition-normal` / `--transition-color` / `--transition-shadow` / `--transition-transform`。

```ts
import { DURATION } from '@apform-ui/core'
```
