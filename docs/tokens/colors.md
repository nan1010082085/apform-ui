# 颜色

主色与功能色定义在 `tokens.css`。

| 类别 | 示例 |
|------|------|
| 主色 | `--color-primary` `#0060A2` |
| 成功 / 警告 / 危险 / 信息 | `--color-success` / `--warning` / `--danger` / `--info` |
| 文字 | `--text-color-title` … `--text-color-disabled` |
| 背景 | `--bg-color-page` / `--bg-color-white` / `--bg-color-gray*` |
| 边框 | `--border-color-base` / `--border-color-light` |

```ts
import { COLORS, TEXT_COLORS } from '@apform-ui/core'
```
