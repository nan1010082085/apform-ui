# @apform-ui

Schema Platform 企业级 Vue 3 组件库。**Storybook 是唯一组件文档入口。**

## 样式接入（与业务一致）

```ts
import 'element-plus/dist/index.css'
import '@apform-ui/core/tokens.css'
import '@apform-ui/core/design-tokens.css'
import '@apform-ui/core/styles/element-override.css'
```

## 文档原则

1. **展示源 = playground Demo**：每个 Story 直接渲染 playground 视图，不另写假样式 demo
2. **样式栈 = 业务应用**：Element Plus + 设计令牌 + element-override
3. **配方优先**：先看「配方 / ListPageRecipe」「配方 / ChatRecipe」，再下钻单组件

## 侧边栏结构

| 分组 | 内容 |
|------|------|
| 配方 | 列表页 / 对话页黄金路径 |
| 基础 | AppDialog、AppIcon、FilterTabs、UserAvatar |
| Layout | PageShell、FilterBar、CardTable… |
| Property | 属性面板控件 |
| Chat | 对话相关 |
| Preview | Schema / 文档预览 |
| 反馈 | EmptyState、StatusTag、Skeleton… |
| 弹框 | FormDialog、ConfirmDialog |
| Composables | useConfirm、useMessage… |
